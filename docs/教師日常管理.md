# 教師日常管理

## 建議設定順序

1. 登入教師管理端。
2. 在「帳號安全」改成自己的管理帳號與密碼。
3. 建立班級並確認班級為啟用狀態。
4. 匯入學生名單。
5. 匯入五座島嶼的正式題庫。
6. 使用測試學生完成挑戰後，確認作答總覽與排行榜。

## 學生登入資料

學生登入需要：

- 班級代碼
- 座號
- 個人 PIN

班級停用後，該班學生暫時不能登入；重新啟用即可恢復。

## 玩家暱稱與裝置登入

- 玩家登入後可到「設定」修改暱稱，長度為 2～10 個字。
- 修改暱稱只會更新地圖、成就與排行榜顯示名稱，不會重設分數、配件或作答紀錄。
- 同一組班級代碼、座號與 PIN 同時只能在一台裝置使用。
- 若玩家改在另一台手機或電腦登入，舊裝置會自動失效；不同時間更換裝置不影響原有進度。
- 請為每位學生建立獨立座號與 PIN，不要讓多人共用同一帳號。

## 題庫規則

- 五座島嶼各 20 題，共 100 題。
- 每題四個選項且只能有一個正解。
- 題目 ID 不可重複。
- 解析與提示不可空白。
- Excel 儲存格換行會保留。
- `**文字**` 顯示為粗體，`__文字__` 顯示為底線。

## 作答紀錄

「作答總覽」會保留每次完成挑戰的資料，可匯出 `.xlsx`，包含學生摘要、逐題明細與題目統計。

## 學期結束

建議先匯出作答紀錄，再刪除不再需要的班級。刪除班級會一併刪除該班學生、進度與作答紀錄，無法從遊戲後台復原。
