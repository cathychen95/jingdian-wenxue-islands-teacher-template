教師獨立部署版 · 1.1.0

八個步驟，建立自己的闖關島

每位教師會擁有自己的公開遊戲網址、教師管理端與獨立資料庫。學生不需登入 ChatGPT。

✓ 獨立學生資料✓ 獨立教師題庫✓ 獨立作答紀錄
GitHub 範本→Cloudflare 部署→專屬網址＋D1
1

準備兩個免費帳號

準備自己的 GitHub 與 Cloudflare 帳號。請勿借用其他老師的 Cloudflare 帳戶，否則資料與管理權可能混在一起。

2

點選 Deploy to Cloudflare

開啟分享者提供的 GitHub 專案首頁，點選藍色部署按鈕，依畫面授權 Cloudflare 讀取並複製範本。

3

命名自己的遊戲

建議使用英文小寫、數字與連字號，例如 jingdian-islands-wang-teacher。不同部署不要使用相同名稱。

4

設定教師首次登入帳密

欄位規則
TEACHER_USERNAME4～50 個不含空白的字元
TEACHER_PASSWORD至少 6 位純數字

這些資料只供教師使用，不要傳給學生。

5

等待 Cloudflare 完成建立

Cloudflare 會建立專屬 Worker、D1 資料庫及公開 workers.dev 網址，並自動套用資料庫遷移，建立完整資料表與單一登入索引。

6

登入教師管理端

開啟新網址，點選「教師管理端」，輸入剛才設定的帳密。登入後先進入「帳號安全」，確認或更換自己的管理資料。

7

建立班級、學生與題庫

  1. 建立班級並保持啟用。
  2. 匯入學生名單與 PIN。
  3. 匯入五島正式題庫 Excel。
  4. 使用測試學生完成挑戰。
  5. 確認作答總覽、排行榜與 Excel 匯出。
8

確認暱稱與登入保護

  1. 以測試學生登入，在「設定」修改 2～10 字暱稱。
  2. 確認地圖與排行榜同步顯示新暱稱。
  3. 在另一台裝置登入相同帳號，確認舊裝置會自動失效。
  4. 確認新裝置仍保留原本分數、配件與作答紀錄。

提醒：每位學生都應使用不同座號與 PIN；同一帳號不能在多台裝置同時使用。

正式交給學生前

  • 測試學生可登入
  • 確認五島各 20 題
  • 確認教師帳密已保存
  • 不要公開學生 PIN 表
  • 確認作答紀錄可匯出
  • 收藏 Cloudflare 管理頁面
